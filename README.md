## Описание проекта
Этот проект представляет собой реализацию доски Kanban на языке Java с использованием современных технологий и паттернов проектирования.

## Используемые технологии

### Backend
- **Java 11+** - основной язык программирования
- **JUnit 5** - фреймворк для модульного тестирования
- **Gson** - библиотека для работы с JSON

### Архитектура
- **Паттерны проектирования** - применение SOLID принципов и паттернов проектирования
- **ООП** - объектно-ориентированное программирование
- **Clean Code** - соблюдение принципов чистого кода

### Дополнительные библиотеки
- **Google Gson** - для сериализации/десериализации данных
- **JUnit 5** - для unit-тестирования

## Особенности реализации
- Интерфейс командной строки
- Работа с JSON-файлами для хранения данных
- Использование паттернов проектирования для создания гибкой архитектуры
- Тестируемость кода через модульные тесты

## Запуск проекта
1. Склонируйте репозиторий
2. Откройте проект в IDE
3. Запустите основной класс `Main` для запуска приложения
4. Используйте команды из CLI для взаимодействия с доской Kanban

## Требования
- Java 11 или выше
- IDE (IntelliJ IDEA, Eclipse и т.д.)
