# Kanban Board — REST API Server

Веб‑приложение для управления задачами в стиле Kanban с REST API серверной частью. Проект реализует полнофункциональную систему управления задачами с возможностью взаимодействия через HTTP‑запросы.

## Функциональность

**Основные возможности:**

* управление задачами (создание, чтение, обновление, удаление);
* работа с подзадачами;
* проверка пересечения задач по времени;
* управление досками и колонками;
* поддержка JSON‑формата для обмена данными.

## REST API Endpoints

### Задачи (Tasks)

* `GET /tasks` — получить список всех задач;
* `GET /tasks/{id}` — получить задачу по ID;
* `POST /tasks` — создать новую задачу;
* `PUT /tasks` — обновить существующую задачу;
* `DELETE /tasks/{id}` — удалить задачу.

### Подзадачи (Subtasks)

* `GET /subtasks` — получить список всех подзадач;
* `GET /subtasks/{id}` — получить подзадачу по ID;
* `POST /subtasks` — создать новую подзадачу;
* `PUT /subtasks` — обновить существующую подзадачу;
* `DELETE /subtasks/{id}` — удалить подзадачу.

### Эпики (Epics)

* `GET /epics` — получить список всех эпиков;
* `GET /epics/{id}` — получить эпик по ID;
* `POST /epics` — создать новый эпик;
* `PUT /epics` — обновить существующий эпик;
* `DELETE /epics/{id}` — удалить эпик;
* `GET /epics/{id}/subtasks` — получить подзадачи эпика.

### Дополнительные эндпоинты

* `GET /prioritized` — получить приоритезированный список задач;
* `GET /history` — получить историю просмотров задач.

## Технологии

* Java 11+;
* HTTP Server API;
* Gson (для обработки JSON);
* REST API;
* JUnit 5 (для тестирования).

## Особенности реализации

* **Проверка пересечения задач** при создании/обновлении — система предотвращает создание задач с пересекающимися временными интервалами.
* **Валидация данных** через HTTP‑статусы — корректная обработка ошибок с возвратом соответствующих статусов (400 Bad Request, 404 Not Found, 500 Internal Server Error и т. д.).
* **Обработка ошибок** с подробными сообщениями — клиент получает понятные описания причин возникновения ошибок.
* **Поддержка CRUD‑операций** для задач и подзадач — полный набор операций создания, чтения, обновления и удаления.
* **История просмотров задач** — отслеживание и хранение информации о просмотре задач пользователями.
* **Приоритезация задач** по времени начала — автоматическое упорядочивание задач на основе временных параметров.
